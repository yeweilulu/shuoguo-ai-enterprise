## 9. Managed-Agent 咨询协同流程（8 步闭环）

> 从客户问题输入到咨询报告输出的完整智能化流程

1. **客户输入** → 客户问题输入：企业提交经营问题和背景数据，系统完成信息结构化与问题分类
2. **任务拆解与路由**：Orchestration Engine 将复杂问题拆解为任务，智能分配至对应专业顾问 Agent
3. **多顾问 Agent 并行分析**：战略、营销、财务、运营等 Agent 同步进行专业领域深度分析
4. **知识检索** → 知识检索与数据验证：每个 Agent 同时调用知识图谱和企业数据进行事实核验，确保分析有据可依
5. **策略仿真与优化**：决策仿真层对候选方案进行竞争模拟、风险评估与场景推演
6. **结论交叉校验**：各 Agent 结论汇总互相验证、消解矛盾，形成一致性高质量结论
7. **报告生成与建议输出**：自动生成结构化咨询报告，包含完整诊断、方案、执行计划与效果预测
8. **持续反馈学习**：跟踪执行效果，将真实反馈回流至知识库与模型，实现持续进化
